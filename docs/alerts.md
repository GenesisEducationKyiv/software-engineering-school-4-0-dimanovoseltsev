### 1. High HTTP Request Rate
**Condition:** The total number of HTTP requests exceeds a certain threshold within a specified time frame.  
**Description:** Triggers when there is a high rate of HTTP requests, indicating a potential spike in traffic or a possible DDoS attack.

### 2. High Error Rate
**Condition:** The percentage of HTTP requests resulting in error status codes (4xx or 5xx) exceeds a certain threshold.  
**Description:** Triggers when there is an unusually high error rate for HTTP requests.

### 3. Long HTTP Request Duration
**Condition:** The average duration of HTTP requests exceeds a certain threshold.  
**Description:** Triggers when the duration of HTTP requests exceeds an acceptable value, indicating potential performance issues.
